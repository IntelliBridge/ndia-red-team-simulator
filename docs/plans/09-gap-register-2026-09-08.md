Produced by a ten-area audit of `docs/superpowers/specs/2026-09-08-adversarial-ml-redteam-spec.md`, `specs/00N-*/spec.md` and `docs/plans/0N-*.md` against `main` at `a864da6` (PR #22 merged). Web UI (`web/`, `packages/`), infrastructure (`deploy/terraform`, Fargate) and Phase B are excluded and listed as such. Ids are `G-*`; the parenthesised aliases are the per-area audit ids. Status is as found at audit time; the review fixes squashed into #22 (`a864da6`) already close the verify defense-match and the upload evaluation-binding parts of G-VER1 / G-ASSET1.

Execution order is four waves (libraries and contracts; worker, audit and API admission; CLI, config, seeding and e2e harness; end-to-end completion criteria and documentation). Each wave is one parallel-writer workflow with disjoint file ownership followed by a single assemble-and-push.
